One frame, filled until it overflows

The bordered rectangle is the content frame. Everything on this page is inside it, and the header and footer above and below are separate static frames that this text never enters.

When the content frame runs out of room the converter starts a new page using the same template, so the header and footer come back with it. The paragraphs below are here to make that happen.
